# Rohit Deogharkar — Portfolio

Personal portfolio site built to showcase my work as a Full Stack (MERN) Developer.

**Live:** [rohit-deogharkar.vercel.app](https://rohit-deogharkar.vercel.app/)

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- [Framer Motion](https://www.framer.com/motion/) for animations
- [Lucide](https://lucide.dev) icons

## Sections

Hero (typewriter intro) · About · Skills · Experience · Education · Projects · Contact

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

Content (name, skills, experience, projects, links) lives in [`src/lib/data.ts`](src/lib/data.ts) — edit that file to update anything on the site.

## Deploy

Deployed on [Vercel](https://vercel.com/new).
